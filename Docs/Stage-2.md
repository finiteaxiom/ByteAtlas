# 阶段 2：真实目录闭环

更新于 2026-09-11。已实现本阶段主要闭环并通过本机自动检查；尚非完整首版交付。此前阶段 1 的硬件绘制与故障补验见 [性能记录](Performance.md)。

## 已实现

- 首页原生选择目录，以单次令牌创建世界；可保留多个入口、恢复缓存，移除入口仅清理应用数据库。
- Utility Process 单任务渐进扫描、暂停、继续、取消和两轮枚举核对。未知、部分、完整、不可用分别记录；取消、离线、枚举失败不会据此批量误删已有索引。重启将中断任务标明，进入世界重新核对。
- SQLite schema 2 管理真实条目、精确逻辑字节数、类型统计、应用 ID、持久化槽位/分组和最后视图。路径改名无法可靠识别时按删除加新增处理。
- 中文、单字符、名称/路径子串搜索；搜索和组成员每页 60 条，支持搜索跳转、聚合成员临时揭示、返回镜头和选择恢复。
- 真目录容量/类型模式、日光/暖暮配色；场景按稳定分区分页，不把全部索引传到渲染端。分组键及槽位保存后不因普通插入排序重排。
- 明确按钮触发默认程序打开、资源管理器定位、复制路径；主进程依可信 ID 解析并再次核对范围和链接。双击文件不启动程序。

实现文件：`src/backend/{scanner,index-store,path-safety}.ts`、`src/main/{catalog-ipc,backend-host,index}.ts`、`src/shared/contracts/catalog.ts`、`src/renderer/{WorldHome,RealWorld}.tsx` 和 `city/catalog-client.ts`。既有 CityRenderer 继续负责图形资源、相机与拾取。

## 边界与预算

仅采集结构和元数据；不读取正文，不跟随目录联接点/符号链接，不写入源目录。应用自身数据处于范围内时明确排除；不静默排除 node_modules、构建产物或 .git。没有自定义排除编辑器。容量为逻辑大小，硬链接可能重复统计。

当前最多一个扫描任务、64 条扫描事务、深度上限 128；达到限制会保留不完整状态。场景普通对象每页 60，搜索及组成员每页 60；桥接等待最多 32 个请求、15 秒超时。界面串行轮询、180 ms 搜索防抖，按 requestId/revision 和当前页面防止过期结果覆盖；历史最多 50 项，目录视图缓存最多 64 项。

初始槽位依目录发现顺序分配，保存后稳定；不保证不同新索引在不同枚举顺序下的全部坐标相同。两轮扫描降低初扫期间变化遗漏，但不提供原子文件系统快照，也不替代阶段 3 监听。
