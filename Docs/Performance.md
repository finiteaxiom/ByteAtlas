# 性能与图形故障记录

2026-09-10 本机实测；不是跨机器性能承诺。Windows 11 build 22631，i7-14650HX，约 16 GiB 内存，RTX 4060 Laptop。系统报告的磁盘型号为 Fanxiang S690 500GB 与 UMIS RPJYJ1T24MLR1HWY，未建立测试卷到物理磁盘的可靠映射。

## 样例硬件绘制

`npm run benchmark:graphics`：111 个虚构文件、10 个目录，窗口 1200×800，实际画布 736×627 CSS 像素；新应用缓存，系统缓存未控制。ANGLE D3D11 确认 RTX 4060 硬件绘制，180 帧交替缩放，32 次绘制调用、10,920 三角形。

- 页面开始至首个场景 438.9 ms，不是进程冷启动总耗时。
- rAF 间隔 P50 6 ms、P95 6.5 ms、最大 169.9 ms；存在单次卡顿，不能只据 P95 宣称全程流畅。
- 每 50 ms 采样的应用进程工作集总和峰值 418,024 KB，约 408 MiB。
- 实际 WEBGL_lose_context 丢失/恢复、构造阶段图形失败、两种失败时列表导航及重新加载恢复均通过。

证据：本地 `.artifacts/stage1-benchmark/benchmark.json` 和截图。软件离屏 smoke 与此硬件测量分别报告。

## 真实目录后台负载

### 2026-09-12：当前解包候选的硬件桌面目录基准

`npm run benchmark:desktop-catalog` 生成 10,000 个空文件、100 个目录的新 fixture 和新 profile；Windows 11 build 22631、i7-14650HX、约 16 GiB、RTX 4060 Laptop，736×627 CSS 像素，硬件绘制，系统缓存不受控。`.artifacts/desktop-catalog-Pv50nF/desktop-catalog-benchmark.json`：

- 扫描 18,155.53 ms，首场景 18,318.20 ms；这包括新 fixture 和完整 Electron 路径，不等同进程冷启动承诺。
- 60 个可见对象，26 次绘制调用，144,552 三角形；rAF 间隔 P50/P95/最大为 6 / 6.5 / 104.1 ms。
- 每 50 ms 采样的全应用工作集峰值为 470,856 KB（约 460 MiB）。

这是一条当前候选、明确条件下的 1 万项硬件记录；它不证明 10 万项桌面绘制、冷缓存、另一 GPU 或整个首版性能通过。

监听的 12 次 fallback/重新启用循环历史用例与 20 秒预跑均通过；预跑实际 34.649 秒，覆盖 270 目录 fallback、变更、暂停/取消、离线恢复和停止释放。24 小时耐久已开始但尚未完成，内存、句柄、脏队列和收敛 checkpoint 仍待完整审阅，不能折算为 24 小时通过。
