# 产品与交互设计

## 目标与平台

电脑世界探索器帮助用户看懂文件归属、发现大文件、找到近期修改的项目，并回到真实文件执行打开与定位。探索的趣味与信息的可解释性同等重要。

首版仅支持 Windows。具体最低 Windows 版本与 CPU 架构需在工程准备阶段依据依赖支持范围确定，不能据此宣称支持所有 Windows 系统。

## 世界规则

| 对象或特征 | 表现 | 约束 |
| --- | --- | --- |
| 用户选择的根目录 | 一个世界 | 首版一次展示一个世界，可保存多个世界入口 |
| 当前目录 | 当前沙盘 | 顶部始终显示路径 |
| 子目录 | 命名街区 | 双击进入下一层 |
| 当前目录直属文件 | 入口附近的公共地块中的建筑 | 保持真实归属 |
| 文件 | 独立建筑 | 可选中建筑对应一个文件 |
| 多文件聚合 | 带数量标识的模型组 | 外观区别于单文件建筑 |
| Git 仓库 | 有入口标识的工业园区 | 内部仍遵循真实目录层级 |
| 文件大小 | 建筑高度 | 固定、单调、压缩映射；详情显示精确值 |
| 近期修改活动 | 暖灯、光晕与辅助标记 | 不宣称代表打开、阅读或运行行为 |

街区使用矩形地块和规则道路。面积依据展示所需空间分配，设置上下界；面积不是严格容量比例。容量比较通过数值和比例条补充。

道路表示街区分隔和进入路径，首版不表达代码依赖或真实磁盘读写流量。树木、路灯等装饰不参与统计，不遮挡可操作对象。

远处显示街区轮廓和概况，中距离显示建筑群，近处显示独立建筑。子目录缩略建筑为内部概况，不提供与当前层混淆的独立文件操作；进入后才展开对应文件。大量直属文件采用稳定分组，搜索可临时揭示目标。

空目录保留空地块。无权限、尚未扫描与真正为空必须具有不同状态。默认不递归跟随符号链接或目录联接点。

## 主流程

### 首次生成

首页选择文件夹后展示路径、元数据本地索引说明及可展开的扫描范围说明，点击“开始探索”进入沙盘。阶段 2 不提供自定义排除编辑器；应用数据目录位于选定范围内时会明确排除，不能选择应用数据目录内部作为世界。

渐进扫描期间即可探索；展示已发现数量与扫描状态。总量未知时不显示百分比。暂停保留已完成数据；取消停止当前任务并保留可标明为不完整的索引，允许再次扫描。移除世界入口只删除应用索引与布局，不删除源目录。

排除扫描与视觉折叠是不同设置：排除项明确标注不计入当前统计；折叠项保留扫描和统计，仅减少视觉展示。不得静默排除依赖目录后将部分统计称为完整容量。

真实世界当前为每层目录提供稳定分区：聚合页展示文件组，其他分区按持久化槽位分页显示目录和普通建筑；每页预算 60 个普通对象。切换分区不改变目录归属、永久槽位或总统计。搜索揭示聚合成员只使用临时展示位。最近启动扫描的一个世界会进入阶段 3 监听与核对；活动模式和 Git 工业园标记已实现，范围与限制见下文。

### 浏览与选中

| 操作 | 行为 |
| --- | --- |
| 左键拖动 | 平移；拖动结束不触发点击 |
| 滚轮 | 缩放并逐步显示细节，不自动切换目录 |
| 右键拖动 | 旋转与受限俯仰，镜头不穿入地面 |
| 悬停 | 轮廓和名称、类型、大小摘要 |
| 单击对象 | 选中并显示右侧详情 |
| 双击目录 | 镜头过渡并进入目录 |
| 双击文件 | 保持详情，不启动外部程序 |
| 单击聚合组 | 右侧分页展示成员，支持筛选 |
| 单击空地 | 清除选中并收起详情 |
| 返回按钮 | 恢复上一次目录、镜头和选中状态 |
| 路径面包屑 | 进入所选祖先目录，优先恢复其已保存视角 |
| 俯瞰当前目录 | 将当前地块纳入视野 |

首次使用仅显示可关闭的简短提示，不强制教学。路径、搜索、详情中的操作均应可用键盘完成；提供同数据来源的列表入口，便于精确选择密集对象，也作为图形不可用时的基础访问方式。

### 当前体验样板（2026-09-12，待用户目视评审）

当前样例和真实世界共用主画布与 `CityRenderer`：轻量顶部栏承载返回、紧凑面包屑、搜索和观察模式；目录列表与详情改为按需展开的覆盖抽屉，默认不挤占城市。画布保留“目录”和“俯瞰”入口，底部状态区保留扫描/完整性/监听的简短状态；图形不可用时仍由同源列表访问对象。

温暖城市以主路、支路、地块边界、树列和留白组织方向感。文件模型族通过档案塔楼、代码平顶/天线、图片立面、文档屋顶等轮廓区分；目录是概况街区，聚合组是多建筑组并标明成员数量，空目录是可选择的空地块。它们不改变文件归属、精确容量或既有持久槽位；道路、绿化和活动柱均不是文件访问或真实读写的证据。

单击会以场景轮廓和详情同时反馈；双击目录、返回和搜索揭示均使用短镜头过渡并恢复保存的视角/选择。容量模式保持固定高度编码；活动模式的暖色柱与 ◆ 显示最近 24 小时摘要，样例 fixture 的活动值仅为确定性演示且明确标为非真实读写；类型模式同时使用模型轮廓、语义色与图例。此样板已实现，尚未表示用户已认可观感或整个首版完成。

### 详情与系统操作

文件详情显示名称、类型、完整路径、逻辑大小、修改时间；提供“默认程序打开”“在资源管理器中定位”“复制路径”。目录详情显示路径、汇总大小、文件与子目录数量、统计完整性以及进入和资源管理器打开操作。

打开只由明确按钮触发。首版不自动读取正文、不生成内容预览、不提供删除、重命名或移动。Git 首版仅识别仓库，不执行 Git 命令查询分支或修改状态。

### 搜索

默认搜索当前世界的名称与路径，支持中文和片段匹配；不搜索正文。结果显示相对路径、类型、大小，采用分页。

选择结果后进入所在目录、恢复或计算布局、临时揭示聚合中的目标、定位镜头并打开详情。搜索跳转加入浏览历史，返回可恢复原位置。未扫描完整时提示结果不完整；失效结果触发局部核对并说明原因。

### 变化与恢复

阶段 3 当前实现：仅监听最近启动扫描的一个世界；切换活动世界会停止旧监听，其他世界保留缓存。句柄预算或监听错误时使用周期核对，并明确该状态；取消扫描也停止该世界监听。周期核对会消耗时间，不承诺所有变化立即出现。活动默认最近 24 小时，使用柱形标记和 ◆ 强度值：首次扫描以修改时间推断，后续监听核对或已完成世界的主动重新扫描才可记录实际观察到的变化。两种来源都不代表真实打开、阅读、运行或读写流量。依赖/构建/Git 路径活动降权到 20%，重复变化不累加，也不改变容量。

当前后台变化通过轮询后的场景快照呈现，不自动跳转，也不应抢镜头。新增淡入、大小变化的专门反馈、大量变化的可展开摘要，以及所选文件删除后保留“文件已不存在”详情并禁用操作，均属于下一轮“状态交互完善”的待实施目标，不能视为本阶段已验收行为。

重新启动先显示缓存和最后核对时间，再后台刷新。根目录不可用时保留离线世界，不把其所有文件判为已删除。

## 观察模式与主题

- 容量模式：高度、数值、目录比例条表达逻辑大小，注明不等同于实际磁盘占用。
- 活动模式：显示时间范围，默认最近 24 小时；初次扫描依据修改时间，开始记录后才有真实观察到的变化记录。
- 类型模式：类型配色和图例，不能只靠颜色辨别。

活动聚合应限制单个文件反复变化的贡献，区分初始推断与已观察变化。构建与依赖目录的活动降权规则需可解释，不影响容量统计。

默认温暖主题使用奶油白、浅木色、低饱和绿与暖橙，简化模型、柔和日光、适度阴影。活动与选中提示分别定义。支持关闭或减少动画。

主题管理颜色、模型族、材质、照明、环境、界面色板；不同模型遵循相同占地与高度包络。主题不改变布局、统计、镜头或选中对象。首版交付一个完整温暖主题，科技主题后续制作。

## 首版之外

多磁盘全景、第一人称漫游、科技主题完整资源、内容预览、Git 分支与工作区状态、历史活动回放、应用与进程可视化、真实读写流量均不属于首版交付。
