# 阶段 1：固定数据温暖沙盘

日期：2026-09-09。范围是可探索的固定数据沙盘，不是完整文件系统工具。

## 已实现

- 三维矩形街区、道路、建筑、树木、园区边界与柔和日光；建筑和装饰按几何、材质实例化绘制。
- 每层目录一张沙盘；直属文件与目录概况分别展示。空目录保留空底板，零字节文件仍有可点击建筑。
- 左键平移、滚轮缩放、右键旋转、沙盘拾取、双击进入、目录列表与详情；镜头俯仰和缩放有界。
- 返回恢复镜头与选择；进入目录提供短过渡，系统减少动态效果设置可禁用过渡。
- 固定高度映射、容量与类型模式。目录类型按实际样例成员的主类型计算，文件详情显示精确字节数。
- 密集目录使用稳定哈希桶聚合，显示数量与稳定编号；成员列表每页 8 项，支持临时展开独立文件建筑。
- 中文名称与路径片段搜索，命中后进入所在目录、定位、揭示并打开详情。仅搜索样例，最多展示 60 条，提示结果上限。
- 日光与暖暮配色共用几何和布局；暖暮是主题验证变体，完整科技主题仍待后续制作。
- 样例布局版本化保存于 localStorage；损坏存储回退为确定性布局，存储写入失败时仍保持会话内稳定。导航历史限 50 步。
- 标签根据视野和碰撞显示；远景省略窗户细节。窗口不可见时暂停请求渲染，静止场景按需渲染。
- 图形创建失败时保留列表；上下文丢失有提示与重新加载入口。该异常恢复分支尚未完成故障注入验收。

## 样例范围

虚构根目录“我的工作空间”包含 111 个文件、10 个目录（含根），不读取磁盘元数据或文件内容。其中有 Git 工业园标记、三级子目录、中文与超长文件名、零字节文件、2 GB 与 64 GB 文件，以及素材仓库的 96 个图像文件。

布局测试覆盖重新排序、增删少量节点后的原位置保留、密集分组插入后成员归属不变、降至低数量后保留聚合状态。样例 UI 没有增删源文件按钮，真实变更监听留待阶段 3。

## 规模与性能边界

测试沿用阶段 0 的 Windows 11 本机，离屏窗口为 1200×800，城市区域约 750×666。全景本次记录 32 次绘制调用、10,920 个三角形；这是当前样例场景的计数，不是性能通过标准。

自检使用软件离屏绘制，普通应用保留硬件加速。尚未测量实际 GPU 帧率、内存峰值或 1 万/10 万文件负载；不能据此承诺这些负载的流畅程度。进入真实目录阶段前，需在约定硬件、分辨率和负载下完成基准并固定响应时间与内存门槛。
